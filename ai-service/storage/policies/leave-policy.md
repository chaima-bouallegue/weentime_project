# Politique des congés (Leave Policy / سياسة الإجازات)

## Congé annuel (Vacances / Annual Leave / إجازة سنوية)

Les employés de WeenTime peuvent demander un congé annuel (vacances) via la plateforme WeenTime.
Le solde de congé annuel est calculé automatiquement par le système.
Chaque employé a droit à un nombre de jours de congé défini par le contrat de travail et la législation en vigueur.

## Procédure de demande de congé

- Les demandes de congé doivent être soumises à l'avance via l'application WeenTime.
- Les demandes de congé sont approuvées par le manager ou les ressources humaines (RH) selon le workflow de l'entreprise.
- Le statut de la demande (approuvée, refusée, en attente) est visible dans l'application.
- En cas de refus, le manager doit fournir une justification.

## Congé maladie (Arrêt maladie / Sick Leave / إجازة مرضية)

- Les congés maladie peuvent nécessiter des pièces justificatives (certificat médical).
- Le certificat médical doit être fourni dans les 48 heures suivant le début de l'absence.
- Les congés maladie sont déduits du solde selon la politique de l'entreprise.

## Télétravail (Travail à distance / Remote Work / العمل عن بعد)

- Les demandes de télétravail sont soumises à l'approbation du manager.
- Le nombre de jours de télétravail autorisés dépend de la politique de l'entreprise.

## Types de congés disponibles

| Type de congé | Description |
|---------------|-------------|
| Congé annuel | Vacances payées, repos annuel |
| Congé maladie | Absence pour raison médicale |
| Congé sans solde | Absence non rémunérée |
| Congé maternité/paternité | Congé parental |
| Congé exceptionnel | Mariage, décès, naissance |
| Télétravail | Travail à distance |
| RTT | Réduction du temps de travail |
| Jour férié | Fête nationale, fête religieuse |

## Règles générales

- Le solde de congé est mis à jour en temps réel dans WeenTime.
- Les jours de congé non utilisés peuvent être reportés selon la politique de l'entreprise.
- Toute absence non justifiée peut entraîner des sanctions disciplinaires.
- Pour consulter votre solde de congé, utilisez la commande "quel est mon solde de congé" dans le chatbot WeenTime.
